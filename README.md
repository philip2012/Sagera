# Sagera

Sagera is a Fedora-based Linux distribution built around KDE Plasma.

## Status

Sagera is currently in early development.

## Base

- Fedora
- KDE Plasma
- Wayland
- RPM / DNF
- Btrfs
- SELinux

## Repository Structure

- `packages/` — Sagera-specific RPM packages
- `branding/` — logos, wallpapers, and other branding assets
- `config/` — system and KDE Plasma configuration
- `image/` — KIWI image definitions
- `scripts/` — development and build scripts
- `docs/` — project documentation
